# AarVaaken – ikoner for Excel-tillegget

Bare ikonbildene som Excel viser på knappen og i tilleggslista for tillegget
«AarVaaken Utvalg». Excel henter knappebilder gjennom en innebygd nettleser som
ikke får lese fra den lokale maskinen, så bildene må ligge på en offentlig adresse.

Repoet inneholder ingen kode og ingen data.
